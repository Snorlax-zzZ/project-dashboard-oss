# 0.2.20 dogfooding 已知限制

- macOS Apple Silicon 与 Windows x64 已有开发环境验证；公开安装包验证范围以对应 Release 为准。Intel Mac、Linux、干净 Win10/11、中文或空格安装路径、完整卸载及冷启动仍有待验场景。
- macOS 安装包使用 ad-hoc 签名，未完成 Apple 公证；Windows 安装包也不承诺代码签名或 SmartScreen 信誉。
- 浏览器预览使用合成模拟数据，不是真实数据 Web 版。
- 会话正文仅保留明确的 HTTP、HTTPS、mailto 链接，其他协议及相对地址只保留链接文字、不保留可点击地址；原始 HTML 转义显示，图片仅显示替代文字。已补危险协议、编码变体与嵌套内容的回归测试。普通外链仍可能离开当前界面，目标站点需自行判断可信度；外链统一交给系统浏览器及 CSP 收紧尚未实现，不能依靠当前 CSP 阻止脚本协议链接。本次修复依靠正文渲染层过滤，不代表对任意外部内容的完整安全认证。
- 会话来源受支持版本、默认目录和读取预算约束，详见 [会话来源](session-sources.md)。数据库列表仅搜索元信息；Antigravity CLI 暂不展示完整正文；DSH、ZCode、Gemini CLI 仅复制会话 ID。
- 收藏与隐藏按来源隔离；旧收藏兼容原四来源。只读解析和缓存不保证恢复任意超长历史的全部项目标签或内容。
- 来源显隐、拖拽顺序、界面语言及外观仅保存在本机 WebView。清除 WebView 数据会丢失这些偏好；不会修改会话、收藏或隐藏文件。
- RepoWiki 是可选外部依赖，尚待开源，目前同样处于 dogfooding。本仓不附带其安装程序，也不保证所有版本兼容；没有兼容工具和已生成内容时不能使用代码知识。
- Windows 具备进程树超时终止与 RepoWiki 适配；合成超时测试不代替所有真实工具版本和真实双机同步验收。Windows RepoWiki 正文交互仍待真实内容验证。
- Mac 0.2.20 英文界面已有浏览器回归，安装版完整英文验收仍待补齐；Windows 开发安装版已验证语言与来源偏好重启恢复。窄窗拖拽的全部边缘场景及所有快捷键组合不宣称已覆盖。
