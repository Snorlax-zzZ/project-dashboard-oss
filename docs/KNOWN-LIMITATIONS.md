# 0.2.14 dogfooding 已知限制

- 安装包仅验证 macOS Apple Silicon，使用 ad-hoc 签名，未做 Apple 公证。Windows、Intel Mac、Linux 未作为完整发布平台验收。
- Windows 的代码知识状态与图查询会返回平台不支持；Git 超时处理也尚未具备与 POSIX 相同的完整子进程树终止保障。
- 浏览器直接打开前端时使用合成模拟数据，不是真实数据 Web 版。
- **会话正文 Markdown 的链接过滤有已确认的缺口**：`javascript:` 链接可以保留在生成的 HTML 中；原生 WebView 中点击执行尚未验证。不要点击来源不可信的会话正文链接，不要把这版视作可安全展示任意外部内容的浏览器。此项保留为后续修复，本次没有宣称已修复。
- 会话来源使用默认用户目录；部分历史项目标签提取仍带固定盘符假设。收藏格式沿用会话 ID 键，隐藏才按来源独立隔离。
- 只读解析采用头尾读取和缓存，不保证列出任意超长会话中的所有历史项目或内容。
- RepoWiki 是可选外部依赖，尚待开源，目前同样处于 dogfooding 阶段。本仓不附带其安装程序，也不保证所有版本兼容；尚不具备该工具和已生成内容的用户，暂时无法使用代码知识功能。
- 0.2.14 修复删除项目确认默认聚焦「取消」；此前原生回归不等于所有配置均已验证。干净机器安装、升级和真实数据反馈仍属于 dogfooding 的目标。
