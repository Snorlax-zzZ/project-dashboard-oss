# 隐私边界

会话标题、摘要及支持的正文从本机工具文件或 SQLite 数据库只读获取，解析缓存、收藏和隐藏保存在本机。隐藏仅改变本 App 列表，不修改其他工具的数据，也不进入跨机同步。

启用共享项目和跨机同步后，配置的数据仓可能包含项目名称、Git 地址、不同机器上的路径、机器显示名、分支及提交状态、提交作者与摘要、变更文件等信息。它们可能揭示工作内容。请使用自己控制的私有数据仓，并检查共享项目范围；源码开源仓不能当作个人状态仓。

为在主机名变化后仍识别同一台设备，应用在需要生成设备身份时尝试读取系统标识：macOS 的 `IOPlatformUUID`、Windows 的 `MachineGuid`；Linux 实现读取系统 `machine-id`，不代表 Linux 已完成发布验收。程序对原值规范化后计算 SHA-256，取前 8 个十六进制字符，与从主机名关键词或平台名推导的短前缀组合为 `machine_id`；前缀可能透露设备类别。已有有效本机配置时沿用保存的 ID；显式设置 `DASHBOARD_MACHINE_ID` 优先级最高，也会覆盖已保存的本机 ID。

系统标识读取可能失败；本轮隐私说明根据代码核对，未重新执行 Windows 真机身份探测。没有有效覆盖值或已保存身份、且探测失败时，程序会报错并停止需要设备身份的同步，不生成假身份兜底；可按错误提示显式设置 `DASHBOARD_MACHINE_ID`。

生成的 `machine_id` 会保存在本机 `local.yaml`，并用于项目注册表、设备目录和状态快照；启用跨机同步后，相关状态数据会携带它进入你配置的数据仓。这条身份生成路径不把原始系统标识写入 `machine_id`，但派生 ID 仍可关联同一台设备，不能视为匿名。设备标识变化、重新安装系统或人工改 ID 可能影响身份关联，不要为脱敏随意修改正在使用的 ID。

本机 `local.yaml` 也可能包含私有项目和绝对路径；缓存含标题、检索摘要及其他会话元数据。提交问题时不要附上这些目录的压缩包。先把截图、日志和复现样例改成合成内容。

应用通过本机 Git 使用已配置的凭据和网络环境。开源安装包不附带作者的同步仓、会话、隐藏清单或凭据。

九个来源的完整路径和读取限制见 [会话来源](session-sources.md)。SQLite 读取使用正常只读连接与读锁，可见已提交 WAL；不复制整份数据库，不写回、迁移或删除工具历史。应用不会读取工具的认证配置。

界面语言、来源显隐、顺序和外观只在本机 WebView 保存；不进入同步数据仓。即使界面切换为英文，真实会话、项目、路径、提交和 Wiki 内容也保持原文，切换语言并不对这些内容脱敏。
