# 隐私边界

会话正文从本机 harness 文件读取，解析缓存、收藏和隐藏保存在本机。隐藏仅改变本 App 列表，不修改其他工具的数据，也不进入跨机同步。

启用共享项目和跨机同步后，配置的数据仓可能包含项目名称、Git 地址、不同机器上的路径、机器显示名、分支及提交状态、提交作者与摘要、变更文件等信息。它们可能揭示工作内容。请使用自己控制的私有数据仓，并检查共享项目范围；源码开源仓不能当作个人状态仓。

本机 `local.yaml` 也可能包含私有项目和绝对路径；缓存含标题、检索摘要及其他会话元数据。提交问题时不要附上这些目录的压缩包。先把截图、日志和复现样例改成合成内容。

应用通过本机 Git 使用已配置的凭据和网络环境。开源安装包不附带作者的同步仓、会话、隐藏清单或凭据。
