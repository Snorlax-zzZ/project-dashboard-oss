# 使用与数据说明

## 会话看板

程序按来源读取用户主目录中的工具历史，支持九个来源，具体路径与格式限制见 [会话来源](session-sources.md)。自定义目录、其他工具版本、Windows WSL 与原生目录混用尚未作为完整兼容场景验收。

工具条右侧「管理来源 Tab」支持显隐与拖拽排序，保存后生效，至少保留一个来源。隐藏来源入口与隐藏单条会话不同。设置 → 界面语言支持简体中文与 English，业务内容保持原文，详见 [界面语言](interface-language.md)。

收藏和隐藏独立保存，隐藏前有二次确认。隐藏后在「已隐藏」中恢复；隐藏不等于源工具的归档或删除。分页总数在过滤隐藏会话后计算。源会话删除后，下次查询不再展示它；如果同一个会话 ID 再出现，原隐藏偏好仍生效。

本机数据在 `~/.project-dashboard/`：

```text
local.yaml                           # 本机配置、私有项目与目录映射
sessions/cache/<source>/             # 可重建的解析缓存
sessions/favorites.json              # 收藏
sessions/hidden.json                 # 按来源区分的隐藏偏好
sessions/.layout-v1.json              # 旧目录导入完成标记
sessions/.write.lock                 # 本机写入锁
dashboard-state-clone/               # 默认同步仓副本
dashboard-state-clone.sync-status.json # 本机同步记录，位于同步仓外
```

设置可以打开会话目录和同步数据目录。外观、语言、来源显隐和顺序由本机 WebView 保存，不参加跨机同步。升级会把旧 `~/.cache/project-dashboard/sessions/` 的有效缓存与收藏导入新目录，旧副本保留；不要并行运行新旧版本。

两个平台的公开应用标识均为 `io.github.snorlaxzzz.projectdashboard`，与 0.2.14 公开版一致。若从标识不同的其他构建切换，WebView 偏好可能需要重新设置。本机配置、会话缓存、收藏与隐藏仍使用同一 `~/.project-dashboard/` 目录。安装前退出已有实例并备份该目录；不要同时运行公开版和开发版。

清理缓存只处理 `sessions/cache/`；不要顺手删除收藏、隐藏或导入标记。缓存中累计的历史项目标签可能无法仅凭会话头尾重新完整获得。备份或恢复偏好前先退出 App 和 CLI，不要把损坏文件直接覆盖为空。

## 项目与跨机状态

只在本机使用时，不必配置同步仓。需要跨机看板时，先准备自己有权限访问的**私有 Git 数据仓**，在仓库中提交 `registry/projects/.gitkeep`，然后把远端地址填入设置。App 要求远端拉取后存在 `registry/projects/` 目录，只有 `registry/` 不足以通过校验。首次保存地址会尝试拉取；本机需已有可用的 Git 与对应认证方式，地址中不要嵌入令牌或密码。

添加项目时填写本机路径和 Git 地址，按界面选择本机或共享项目。共享项目通过 UUID 关联不同机器上的路径。协作看板显示各机器已采集并同步的状态，不是远程控制，也不是各机器的实时文件浏览器。

点击「手动同步」会执行实际采集与 Git 同步。最近成功或失败记录只代表本机对应远端的同步尝试；会话刷新不是跨机同步。修改设置后请以界面返回的保存结果和同步结果为准。

## 代码知识

RepoWiki 工具尚待开源，目前同样处于 dogfooding 阶段。代码知识入口随本版保留，但尚不具备该工具和已生成内容的用户，暂时无法使用此功能。

这是可选的 RepoWiki 浏览集成，本仓不附带 RepoWiki CLI 或为项目生成知识内容。使用前需要已有兼容工具、配置 CLI 的绝对路径和数据根，并在项目中生成正式 `.repowiki/` 内容。缺少这些条件时，其他页面仍可使用。

状态和图查询具备 macOS / Windows 平台适配；Windows 需要兼容的原生 RepoWiki 工具。程序只在用户进入或操作相关页面时查询，不自动启动知识生成任务。没有工具或真实项目时，只能验证空状态。

目录搜索按标题筛选并保留祖先层级；文档查找只查当前已打开正文，支持高亮、上一处/下一处、⌘F / Ctrl+F、Enter / Shift+Enter 和 Esc，不建立全库正文索引。
