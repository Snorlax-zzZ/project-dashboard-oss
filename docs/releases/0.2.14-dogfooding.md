# 0.2.14 dogfooding

首个公开测试版本，保留当前会话、Fleet、项目管理、代码知识和设置五个入口。

包含四来源会话浏览、搜索分页、收藏、隐藏与恢复、隐藏二次确认、本机会话目录统一、同步状态持久化，以及此前完成的弹窗焦点和布局修复。UI 沿用当前浅色与深色方案。

代码知识依赖的 RepoWiki 工具尚待开源，目前同样处于 dogfooding 阶段。本次仅公开看板中的浏览集成，不包含 RepoWiki 工具本身；尚不具备该工具和已生成内容的用户，暂时无法使用代码知识功能，其他入口仍可按各自前提使用。

首发平台为 macOS Apple Silicon。App 内部版本仍为 0.2.14，Release 使用 dogfooding 标签区分发布阶段。公开版应用标识为 `io.github.snorlaxzzz.projectdashboard`，与旧开发安装包不同，但仍共用 `~/.project-dashboard/` 本机数据；外观偏好可能需要重新设置。安装前请退出已有实例并做好备份，不要同时运行两个版本。

公开源码不包含开发仓 Git 历史、内部审计、会话或配置。图标由 SVG 在构建时生成。安装包应从经过导出的源码构建，并随同发布 SHA-256 校验文件与构建记录。

完整限制见 [已知限制](../KNOWN-LIMITATIONS.md)，数据范围见 [隐私边界](../PRIVACY.md)。
