# 0.2.20 dogfooding

继续作为 dogfooding 版本提供，不承诺生产级稳定性。

## 功能变化

- 会话来源由四个扩为九个，新增 OpenCode、Antigravity CLI、DSH、ZCode 和 Gemini CLI；各来源保留分页和搜索条件。
- 来源 Tab 支持显隐、按钮排序、键盘操作及拖拽；保存与取消分离，偏好在本机持久化。
- 五个入口支持简体中文与 English，真实会话、项目、路径和 Wiki 保留原文。
- 更新侧栏、深浅主题和布局；RepoWiki 目录树支持标题筛选，当前文档支持查找、高亮与快捷键。
- 增加 Windows x64 平台适配，包含本地文件访问、子进程超时处理和可选 RepoWiki 集成。
- 新收藏按来源和会话 ID 隔离，并兼容原四来源的旧收藏；隐藏仍须二次确认。
- 修复会话正文的危险协议链接过滤：仅保留明确的 HTTP、HTTPS、mailto 链接，HTML 转义显示，图片仅保留替代文字。补充设备标识生成、保存与同步的隐私说明。

## 公开构建

公开版两个平台的应用标识继续使用 `io.github.snorlaxzzz.projectdashboard`，与 0.2.14 公开版一致。公开资源使用纯 SVG 表达当前 PD 标志，构建时生成安装图标。

第三方声明包含当前平台依赖以及内嵌的 SQLite / zstd 信息。Mac 与 Windows 的构建入口见 [README](../../README.md)。可用安装包与 SHA-256 以 Release 实际附件为准，Windows 开发环境验收不代表公开安装包已经复验。

本次来源适配不修改原工具的数据，不新增真实数据 Web 服务，也不将收藏、隐藏或界面偏好加入跨机同步。

## 验证边界

开发版本在 macOS 与 Windows x64 已有自动化及部分原生验证。Mac 原生英文全流程、Windows Wiki 正文、干净系统和真实双机等范围仍待补齐，详见 [已知限制](../KNOWN-LIMITATIONS.md)。RepoWiki 本体尚待开源，同样处于 dogfooding。

升级前请退出旧实例并备份本机数据目录；不要同时运行不同构建。发现问题时只提交脱敏复现资料。
