# 会话来源支持说明

会话看板的来源 Tab 使用工具名称。窄窗口可点击两端箭头滚动工具条，也可聚焦 Tab 后用左右方向键、Home、End 切换。各来源保留独立的搜索条件和页码，只有选中来源才会读取历史。

点击工具条右侧的圆形「管理来源 Tab」图标，或进入设置 → 会话来源 Tab，可勾选要显示的工具。拖动每行左侧的六点手柄，到目标行上半或下半后放下，可插到该项之前或之后；插入位置有高亮线。窄窗口拖到列表上下边缘可滚动。也可继续用上移/下移按钮和键盘排序。

拖拽只修改草稿，不改变勾选；点击「保存」后生效，至少保留一个来源。拖到面板外放下或取消拖动不会提交排序。「取消」、Escape 或点面板外会丢弃整个草稿。「恢复默认」将草稿恢复为全部九来源及默认顺序，仍需保存。

只调整顺序或隐藏其他工具时，当前来源的搜索、分页和详情保留；隐藏当前工具后切到第一个可见来源。键盘导航遵循可见顺序。隐藏 Tab 只收起工具入口，随时可重新显示；与隐藏单条会话是两个独立功能。

显示偏好和外观一样保存在当前 WebView 的本机 localStorage（`pd-session-sources-v1`），重启保留，不进入同步仓或工具目录。清除 WebView 数据后恢复默认；浏览器预览与桌面 App 各自保存，不共享选择。存储写入失败时面板明确提示，当前设置不会假装已经生效。

| 工具 | 历史与详情 | 复制动作 | 当前限制 |
|---|---|---|---|
| Claude Code | 现有活动会话与近期对话 | `claude --resume <sid>` | 保持原扫描范围 |
| Codex | 现有活动会话与近期对话 | `codex resume <sid>` | 不包含归档和内部子会话 |
| pi | 现有会话与近期对话 | `pi --session <sid>` | 保持原行为 |
| Grok | 现有会话与近期对话 | `grok --resume <sid>` | 未提供改动文件记录 |
| OpenCode | 本地 SQLite 会话列表与近期文本 | `opencode --session <sid>` | 列表搜索标题、目录、项目和 ID，不全文检索数据库正文 |
| Antigravity CLI | 当前 CLI 保存的标题、目录、时间与摘要 | `agy --conversation <sid>` | 正文为未适配的二进制结构，暂不展示完整对话；不合并旧目录或 IDE 数据 |
| DSH | v4 压缩日志与近期文本 | 会话 ID | 尚无已验证的外部恢复入口；其他日志版本明确提示不支持 |
| ZCode | 本地 SQLite 会话列表与近期文本 | 会话 ID | 尚无已验证的外部恢复入口；列表搜索元信息，排除已删除、已归档和子会话 |
| Gemini CLI | 本地保存的 JSON 历史与近期文本 | 会话 ID | 与 Antigravity 分开；工具未安装时仍可读已有历史，不承诺恢复命令可执行 |

所有来源均只读原工具数据。数据库适配会读取已提交的 WAL，使用 SQLite 正常读锁，不执行写入、迁移或 checkpoint。工具未产生历史时显示空列表；数据库锁冲突、损坏或未知格式显示读取错误，可处理后点「重新读取」。

OpenCode 默认读取 `~/.local/share/opencode/opencode.db`，设置了绝对路径 `XDG_DATA_HOME` 时跟随该路径；ZCode 读取 `~/.zcode/cli/db/db.sqlite`；Antigravity CLI 读取 `~/.gemini/antigravity-cli/conversation_summaries.db`；DSH 读取 `~/.dsh/sessions/`；Gemini CLI 读取 `~/.gemini/tmp/*/chats/`。自定义数据目录或其他工具版本尚未验证，不会搜索整个用户目录来猜位置。

DSH 和 Gemini 列表初次对单文件最多解析前 1 MiB，随后复用 `~/.project-dashboard/sessions/cache/<source>/` 中的缓存。列表标题和可检索文本可能只覆盖该片段；修改源文件后缓存失效。详情对选中文件扩大到最多 64 MiB，达到预算或遇到正在写入的尾部会明确提示“不保证是最新对话”。数据库来源直接查询原工具已有的索引和元信息，不复制整份数据库，不在分页时扫描所有正文。近期文本最多显示五个用户回合，长消息缩略。

收藏和隐藏继续保存在看板本机数据目录，均不写回工具、不参与跨机同步。新收藏使用「来源 + 会话 ID」隔离。旧收藏仍对原四来源生效；在某来源修改后，只覆盖该来源，不抹掉其他来源原有收藏。隐藏仍需二次确认。

开发版本已在 macOS 与 Windows x64 的已有工具数据上验证列表、分页和抽样详情；不代表其他工具版本、自定义目录或干净机器已验收。SQLite 与 zstd 随应用内嵌，用户无需安装系统数据库或解压工具。公开安装包范围见 [已知限制](KNOWN-LIMITATIONS.md) 和 [发布说明](releases/0.2.20-dogfooding.md)。
